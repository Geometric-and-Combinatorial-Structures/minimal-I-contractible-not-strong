\section{Data and code availability}\label{sec:data}

The public repository (Section~\ref{sec:intro}) contains the C implementation (\protect\path{src/}), run-specific compiled sources and archived scripts (\protect\path{yuca/}), aggregate counters and slice registries, the graph lists (\protect\path{data/}), independent Python implementations (\protect\path{tools/}), regenerated certificates, figures and manuscript sources, and the version-2 classifier and campaign pipeline prepared for the recomputations (\protect\path{v2/}). Commit \texttt{4a059b5} is the state examined in the first round of the external audit. The per-slice output archive is retained on YUCA; the public repository contains summaries and registries rather than every raw output file. In commit \texttt{4a059b5} the p011 worker in \protect\path{yuca/as_run/} is misidentified; since commit \texttt{892e41b} the repository holds the identified worker under that name and keeps the misattributed file unchanged under another name (Appendix~\ref{app:cluster}); a copy of the identified worker also accompanies the manuscript sources (\protect\path{appendix_data/}). The release that accompanies publication will be archived with a persistent identifier.

The repository records the independent checks: the Python verification written from scratch (\protect\path{verification/indep.py}) and its report, the Wolfram Language code and outputs (\protect\path{verification/wolfram_codigo_y_salidas.json}), and the comparison of the manuscript with the data (\protect\path{paper/NUMERIC_CHECK.md}). The script \texttt{verify.sh} checks listed finite certificates and, when \texttt{gcc} and \texttt{geng} are available, the C results and table rows through order $9$; \texttt{-{}-full-table} requests rows $10$ and $11$ as well. Missing dependencies cause levels to be skipped, so exit status $0$ must be interpreted together with the log. With both dependencies present it passes all $39$ checks (16 October 2026). It does not certify the original large enumerations or every structural claim. Code is released under the MIT licence and data under CC~BY~4.0.

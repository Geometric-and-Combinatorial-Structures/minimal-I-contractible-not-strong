\section{Data and code availability}\label{sec:data}

The public repository (Section~\ref{sec:intro}), at commit \texttt{4a059b5}, contains the C implementation (\protect\path{src/}), run-specific compiled sources and archived scripts (\protect\path{yuca/}), aggregate counters and slice registries, the graph lists (\protect\path{data/}), independent Python implementations (\protect\path{tools/}), regenerated certificates, figures and manuscript sources. The per-slice output archive is retained on YUCA; the public repository contains summaries and registries rather than every raw output file. The p011 worker in \protect\path{yuca/as_run/} is misidentified; Appendix~\ref{app:cluster} records the correction, and a hash-verified copy of the appropriate worker accompanies this revision in \protect\path{appendix_data/}.

The audit supplement supplies the new numerical and Wolfram checks, structural recomputation, provenance comparisons, bibliography audit and source diff. The script \texttt{verify.sh} checks listed finite certificates and, when \texttt{gcc} and \texttt{geng} are available, the C results and table rows through order $9$; \texttt{--full-table} requests rows $10$ and $11$ as well. Missing dependencies cause levels to be skipped, so exit status $0$ must be interpreted together with the log. The default run in this audit passed all $31$ available checks with both dependencies present. It does not certify the original large enumerations or every structural claim. Code is released under the MIT licence and data under CC~BY~4.0.

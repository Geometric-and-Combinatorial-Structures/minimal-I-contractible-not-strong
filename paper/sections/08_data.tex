\section{Data and code availability}\label{sec:data}

The repository \repo\ contains: the C program used in the search (\texttt{src/atascadas.c}); the SLURM scripts exactly as submitted and the source as compiled for each run, with SHA-256 checksums (\texttt{yuca/}); the complete logs of the three cluster runs, including the registry of all $\num{2000000}$ slices of the $n=14$ search, the list of duplicated slices, the per-task accounting (\texttt{sacct}) and the counters of the filter cascade; every graph found, in \texttt{graph6} format with English headers (\texttt{data/}); dependency-free Python implementations of exact $\IS$ membership with deletion traces and of integer homology by Smith normal form (\texttt{tools/}), independent of the C code; human-readable certificates regenerated by those tools (\texttt{certificates/}); the figures and the script producing them (\texttt{figures/}); and the \LaTeX\ source of this paper. The script \texttt{verify.sh} re-derives every finite certificate behind Theorems~\ref{thm:A}, \ref{thm:B} and~\ref{thm:D} and the rows $n\le 9$ of Table~\ref{tab:card} (rows $10$ and $11$ with \texttt{--full-table}) and exits with status $0$ only if all checks pass. Code is released under the MIT licence and data under CC~BY~4.0.

\subsection{\texorpdfstring{The twenty graphs of order $12$ in $2$-Dis$\setminus1$-Dis}{The twenty graphs of order 12 in 2-Dis minus 1-Dis}}\label{app:strictly2dis12}
Table~\ref{tab:strictly2dis12} lists the $20$ connected graphs on $12$ vertices that are $2$-dismantlable but not $1$-dismantlable, as returned by a separate run in mode \texttt{2dis\_no\_1dis} over all $\num{164059830476}$ connected graphs of order $12$ ($\num{4000}$ slices, none missing; the total agrees with Table~\ref{tab:card}). Each listed graph is verified individually: its $2$-dismantling sequence is in the repository, and the exact decision of the C program and the independent Python implementation both show that it is not $1$-dismantlable. That no other graph of order $12$ has this property is subject to the same premises as row $12$ of Table~\ref{tab:card} ($\mathrm{H12}$ and Appendix~\ref{app:cluster}).

# Manuscript sources

Version 4 (16 Oct 2026) of *Small non-strong I-contractible graphs and odd torsion in flag complexes* (J. F. Espinoza, M. E. Frías-Armenta, R. G. Hernández-Amador, H. A. Hernández-Hernández). The files that come from the Overleaf project `manuscrito_v4_overleaf.zip` (SHA-256 `7f3f6b62…`) are byte-identical to it; its `main.bbl` is not tracked. `README.md`, `CAMBIOS_v3.md`, `REVISION_LOG_round1-2.md` and `NUMERIC_CHECK.md` are additional files of this repository. `main.pdf` is the reference build (Tectonic/XeTeX, 33 pp.); the pdfLaTeX build used on Overleaf has not been checked here.

`main.tex` (`amsart`, 11 pt) with `sections/`, `tables/` (generated from `../data/` by `make_tables.py`, run from `paper/`), `figures/` (PDF; sources in `../figures/`), `appendix_data/` (`traces.txt`; `tarea_n14_p011_correct.sh`, the task script run by the p011 front of the n = 14 search, identical to `../yuca/as_run/tarea_n14_p011.sh`), `refs.bib` and `elsarticle-num.bst`. Compile with `./build.sh` (pdfLaTeX) or `tectonic main.tex`; on Overleaf use pdfLaTeX (`COMPILAR_EN_OVERLEAF.md`). `CAMBIOS_v4.md` lists the changes from version 3 (round 2 of the external audit, proposals P1 and P4, and further corrections); `CAMBIOS_v3.md` lists those from the authors' Overleaf version.

`make_tables.py` reproduces the three tables `tables/table_cardinalities.tex`, `tables/stuck51.tex` and `tables/strictly2dis12.tex` byte for byte. It writes `^` in graph6 strings as `\textasciicircum{}`, so that the strings copy correctly from the PDF; version 3 used `\^{}`, a circumflex accent that copies as U+02C6.

Versions: v1 (2026-10-13, 38 pp.) → internal adversarial review (`REVISION_LOG_round1-2.md`, `NUMERIC_CHECK.md`: 2 rounds, 45 findings, 42 numerical checks; both files refer to the v1/v2 text) → v2 (2026-10-13, 41 pp.) → v3 (2026-10-16, 32 pp.; the authors' Overleaf version with the corrections listed in `CAMBIOS_v3.md`) → v4 (2026-10-16, 33 pp.; `CAMBIOS_v4.md`).
